# 鱼的记忆 🐟

单文件日记 Web 应用（index.html），底部四 tab：日历 / 海洋 / 统计 / 我的。

## 功能

- 📅 **日历首页**：按月查看，节假日/调休标注（2024–2027 官方安排），当天日记列表
- 😊 **涂鸦心情脸**：16 种手绘表情，默认显示常用 6 个，可展开
- 🌤️ **定位/手动输入城市** → 自动当天天气（Open-Meteo + wttr.in 双数据源）
- 📸 照片上传（自动压缩，最多 6 张）、🎤 点击录音
- 🌊 **心情海洋**：公开的日记会变成小鱼游在海里，点击可查看
- 📊 **统计页**：按周 / 按月切换，可左右翻页看历史区间
  - 心情占比环形图 + 记录日/公开数/平均心情
  - 心情趋势：一天一根柱，颜色是当天主导心情，附「比上一段多/少几篇」
  - 写字量：总字数、平均字数、照片数、语音数、最长的一篇
  - 天气与心情：晴/雨/阴/雪分组下的平均心情，以及常出现的地点
- 👤 **我的**：自定义昵称与头像（小鱼脸或自己的照片）、4 套主题皮肤、导出 JSON 备份、清空数据

## 主题

蒂芙尼蓝 / 蓝紫极光 / 樱花粉 / 浅蓝海风，切换入口在「我的 → 主题皮肤」，保存在本地。

## 使用

浏览器直接打开 `index.html` 即可，数据保存在浏览器 localStorage。

- `xinqing_diary`：日记数据
- `xinqing_theme`：主题
- `xinqing_profile`：昵称与头像

## 后续：小程序版

页面结构已按小程序 tabBar 组织（四页 + 编辑页），迁移时：

- 日历 / 统计 / 我的 → 三个 tab 页，编辑页走 `navigateTo`
- 心情涂鸦 SVG 改为 `<image>` 或 canvas 绘制（小程序不支持内联 SVG）
- 天气接口需在小程序后台配置 `request` 合法域名（open-meteo.com、wttr.in、bigdatacloud.net）
- 录音 / 相册改用 `wx.getRecorderManager`、`wx.chooseMedia`
- 数据先用 `wx.setStorageSync`，后期可换云开发数据库
