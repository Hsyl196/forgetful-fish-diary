# 一条没有记性的鱼 🐟

单文件日记 Web 应用（index.html），功能：

- 📅 日历首页：按月查看，节假日/调休标注（2024–2027 官方安排）
- 😊 涂鸦心情脸：常用 6 个 + 展开更多
- 🌤️ 定位/手动输入城市 → 自动当天天气（Open-Meteo + wttr.in 双数据源）
- 📸 照片上传（自动压缩，最多 6 张）
- 🎤 点击录音
- 🎨 三套主题：蒂芙尼蓝 / 蓝紫极光 / 樱花粉

## 使用

浏览器直接打开 `index.html` 即可，数据保存在浏览器 localStorage。

## 同步说明

- 代码：本仓库
- 日记数据：存于各设备浏览器本地，暂不跨设备同步
